# 0.2.6-t8.2 与 ComfyUI 1.3.3 修复说明

基于上游 v0.2.6，汇总发布后六批本地联合审查的修复。应用、Control 和原生引擎沿用原有分版本管理；节点保持 14 个公开 ID 与协议 1。

## 启动与模型设置

- 托管配置使用与网页一致的 CUDA 12/13、AMD 分型引擎选择，并支持已有 DeepSeek 本地 pack。DeepSeek 保持纯文本、最多 8K 上下文，保留显式速度设置。
- 防止托管配置覆盖 engine-* 目录；保留自定义模型 API ID。模型设置、端口和已有显式选项按实际服务显示。
- 后台任务线程启动失败时退出处理中状态并显示错误；停止失败可见。可选更新检查无法启动时，首次模型设置页与无头启动仍可继续。
- 环境诊断即使发行清单损坏也保留可用报告；依赖失败返回失败状态。

## 更新、回退与上游同步

- 应用更新核对预检后的文件、目标安装身份与实际复制内容；失败后完整回滚的原计划可以重试。
- 更新和回退计划的控制文件成对发布。取消、清理失败或用户新增文件不会误删真实备份、其他安装副本或已发布计划仍依赖的文件。
- 成功更新后的临时组件可按归属回收；保留离线回退与用户配置。
- 上游同步取消时只撤销本次未完成的合并；已完成提交和用户替换的合并保留。原有 T8 功能仍通过独立审查后发布。

## 视频与语音

- 视觉组件或语音设置变化后不混用旧进度；GPU 到 CPU 的既有自动回退不会被当作用户更换配置。
- 验证持久化记录的身份、归属、原片绑定与必要字段。错误记录逐项跳过并保留；不猜测删除未知文件。
- 原片先删除媒体再删除记录，文件被锁时保留回收依据。删除失败可重试，错误 checkpoint 不消耗版本。
- 在上传、静音、缓存命中及最终返回路径补齐取消检查。
- 巨大时间数值和语音时长换算溢出返回明确校验错误。保留原有有效时标及采样舍入行为。
- 损坏的深嵌套语音缓存按原流程重算；损坏的可选语音配置不会连带阻断纯视频，原配置文件保持原样。

## ComfyUI

- 自动语音与视觉阶段共用连接档案锁，并核对阶段间配置、设备和运行时身份；手工字幕路径保持独立。
- 语音准备使用已有显存交接流程，取消后不启动后续服务。兼容旧运行包的能力协商。
- 生成、采样及 Control 的迟到取消在释放资源后仍向上传递；原操作错误优先级保留。
- 视频进度启动清理仅针对已知命名的过期常规文件，跳过未知 JSON、目录和链接；其他旧文件 I/O 失败不阻断无关初始化。当前记录校验及配额不放宽。
- 主端语音契约通过同步工具共享，附来源提交与文件摘要。

## 验证与分发

审查采用真实本机 HTTP、小型 CPU 媒体与子进程、临时目录、实际 PowerShell 更新回退及临时 Git 仓库；故障注入与正常路径均有回归测试。发布前完整回归和完整环境升级结果记录于本版 Release。

本轮没有重新测量大模型推理速度、显存或语音识别准确率，不将自动化通过解释为所有显卡或长片理解质量已验证。既有硬件范围见 [0.2.6 迁移验收](VALIDATION-UPSTREAM-026-T8.md)。

完整环境包包含 Python、依赖、CPU 语音运行环境、EXE 和原生引擎；VisionReady 另含视觉权重和配置。主模型、MTP 与语音模型独立安装。节点 ZIP 不含环境或模型。更新器保留模型、设置和本机私有数据。私有 roadmap 与本地审查日志不进入仓库或分发包。
