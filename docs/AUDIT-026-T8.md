# 0.2.6-t8.1 发布前联合检查

2026-10-28 完成三轮检查，每轮包含 20 个独立范围和双方互审。以下为确认并修复的问题；重复运行回归不作为新一轮。

## 整合包

- DeepSeek 切换速度时保留未修改的上下文，正确处理带值的 `--vision off`；新选 DeepSeek 不继承 Qwen 视觉设置，不兼容选项在停止服务之前拒绝。
- 连续切换模型时，Windows 暂未释放旧端口可使用空闲端口，页面跟随实际地址，同时保留尚未提交的用户编辑。
- 保存的等号形式上下文和显式速度正确显示；首次启动按模型族传递参数。已有设置页时不再悄悄忽略新的命令参数。
- API 连接提示以实际服务的鉴权状态为准，不返回密钥。
- 分卷合并失败只清理本次临时文件，可以重试；旧临时文件和已有完整 ZIP 保留。损坏历史记录不会隐藏有效回退项。
- ASR 的相对模型/VAD 路径统一按应用目录解释；不可读的可选语音资产不阻断纯视频能力查询。
- 恢复身份包含语音配置与资产，变化后拒绝混用旧转录。上传结束时仍检查取消状态；视频源和进度记录共同受存储配额约束。
- 视频进度先续期源再发布，写入失败不消耗任务版本，可以重试。

## ComfyUI 1.3.2

- 使用进度记录本身的到期时间，复制文件不会延长有效期；替换记录时不重复计算旧文件大小。
- 排队后重新读取进度，清除发生在取得服务使用权之后，旧任务的最终提交不会让已清除的阶段复活。
- 排队期间连接配置变化时，在启动托管服务或准备语音之前拒绝旧任务，提示重新执行。
- 节点 ID、协议 1 和默认关闭的可选功能保持不变。
