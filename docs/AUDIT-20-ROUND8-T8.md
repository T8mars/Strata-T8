## 修复范围

整包补丁版 `0.1.40-t8.3` 保持上游源码/原生引擎 `0.1.40.2`、Python `3.12.10` 和协议 1。不更换或下载模型。VisionReady 保留视觉权重、配置和许可证，主模型/MTP 独立分发；NoModels 不含权重。节点补丁版 `1.0.7` 修复实际发行 ZIP 的托管入口元数据缺失，以及打包版本/兼容元数据门禁。

新增整包 `tools/test_portable_round8.py` 的 13 个方法使用实际 socket、实际子进程和两个请求线程；0.18s 测试时限用于快速证明读取是否遵守总时限，生产总时限仍为 30s。冻结旧源码显式前置导入路径，得到 14 个失败子案例、1 个错误，不将误导入当前源码的运行作为基线证据。修复后 13 个方法通过，交叉补充检查发现的 READY 后解析和首次 lazy 失败均已纳入回归。20 个轮次不代表 20 个独立 BUG。

20 轮定向检查均通过，无失败、错误或跳过。节点 239 项回归通过，官方 ComfyUI 0.38.0 V3 CPU 探针通过且 CUDA 未初始化。网页两个 JavaScript 入口通过语法检查；这不表示已进行浏览器视觉验收。

最终完整严格回归：应用 **1203 项 / 490.766s**、安装器 **397 项 / 47.750s**、独立节点 **239 项 / 33.843s**，共 **1839 项**，零失败、错误和跳过。此前 1199 项通过后，交叉复核增加启动边界修复，已重新执行完整 1203 项，旧结果未替代最终源码。20 轮定向集另外执行 143 项，其次数不与完整回归相加。更新本机自有且空闲的 `127.0.0.1:8082` API，确认新代码启动、协议 1、按需加载、双原生进程未运行；保持既有本机鉴权设置，不加载模型。

节点 [1.0.7 发布工作流](https://github.com/T8mars/Comfyui-Strata-T8/actions/runs/37651701404) 的 Windows/Linux 检查及官方 Registry Action 均成功。公开 GitHub ZIP 的全部 15 个成员、完整 SHA256、清单和已发布提交逐项核对，实际解压后的托管最低版本检查通过；发布后初次 Registry 状态为 Pending，不能当作 Manager 上架已完成。
