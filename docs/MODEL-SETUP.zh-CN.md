# 整合包模型设置

双击 **Strata-T8.exe** 打开本地网页，`START-HERE.bat` 保留兼容。无需先安装主模型，无需安装 Python；分发时压缩整个程序目录，保留 `runtime` 等依赖文件夹。其他批处理用于维护。

## 已有独立模型包

1. 将分发者提供的完整模型包解压到 SSD，通常得到 **Strata-data** 文件夹。
2. 在网页选择该文件夹，或点击发现的本机模型。
3. 点击 **检查目录** 确认主模型和辅助文件齐全。
4. 点击 **保存并进入**。页面在后台配置并启动服务，然后进入聊天。

程序不会复制几十 GB 的模型到整合包；其他磁盘上的路径会保存在本机配置中。官方模型和准备完整的 SC117 模型均可选择。仅选择内部的 GGUF 文件夹会提示目录不完整。

## 尚无模型或只有官方 GGUF

展开 **下载 / 准备官方模型**，选择独立保存目录。完整下载最多约 89GB，另需模型预处理空间；确认流量和磁盘需求后才能开始。优先 ModelScope，其次国内镜像，再尝试 Hugging Face，固定版本和 SHA256 沿用现有下载器。

已下载的官方 IQ3_S GGUF 可放到所选目录的 `models/IQ3_S` 内；程序复用已校验的文件并补齐索引、Tokenizer 和 MTP。任务完成后选择准备好的目录，再保存设置。保留启动窗口，处理中可展开日志；中断后重试会复用已有校验通过的文件。

官方准备入口只处理官方 IQ3_S，不将 SC117 等其他变体混入相同目录。其他变体请选择其完整模型包。普通启动、发现、检查和导入不下载模型。

## 更换模型与服务地址

聊天页点击 **模型设置** 返回该网页，点击其他模型卡片即可自动校验、停止本启动器的服务并切换。手动输入目录时点击 **保存并切换模型**；输入无效或新端口被其他程序占用时，保留当前服务。SC117 变体显示为 **SC117 Uncensored · IQ3_S**，聊天页也显示这个名称。

NVIDIA 用户要选择聊天页的原生视频模式，在 **运行设置** 中选 **NVIDIA GPU 视觉**，勾选 **启用 NVIDIA 原生双帧视频分析** 并保存。保持关闭时使用抽帧分析，AMD 文本配置不提供原生视频。后续双击启动器自动进入已配置的聊天服务。

设置页只监听本机，默认从 17880 开始选择空闲端口；聊天/API 默认 8080，冲突时选择其他空闲端口，以页面显示的地址为准。OpenAI Base URL 为聊天地址加 `/v1`。关闭启动窗口或 Ctrl+C 会结束本启动器的服务，不操作其他程序的端口或进程。

连接 DSH 等客户端时，选择 **OpenAI 兼容接口**，复制设置页 **API 连接 · DSH** 中的 **OpenAI Base URL** 和 **API 模型 ID**。这里显示当前服务实际返回的名称，卡片的友好名称不能用来代替它。未启用 API Key 时，客户端要求填写可用本地占位值 `strata`。

新保存的 SC117 配置使用模型包指定的 `sc117-qwen3.8-flash-next-abliterated-iq3_s`；已有配置保留原来的调用名称，直至重新保存模型设置。当前服务对应的卡片显示实际 API ID，其他卡片显示保存配置后使用的 ID。点击卡片中的 **复制 ID**，或选中只读文本按 Ctrl+C，即可复制；复制不会切换模型。也可通过 **API 连接 · DSH** 或服务的 `/v1/models` 查询当前名称。

模型按需加载，第一次文字、图片或视频请求可能需要等待。没有视觉权重的 NoModels 版本可先使用文本；VisionReady 包含兼容 Qwen 的视觉权重，Windows AMD 保持文本配置。

## 局域网 API

默认仅本机访问。展开 **API 访问设置 · 本机 / 局域网**，选择 **开放局域网 API**，点击 **生成密钥**、**复制新密钥**，再保存。密钥至少 16 位；保存时自动停止并重启本启动器的模型服务，正在生成的回答会中断。尚未配置模型也能先保存访问设置。

服务就绪后，**API 连接 · DSH** 显示 **局域网 Base URL**。同一局域网的 DSH、ComfyUI 或其他 OpenAI 客户端填入该地址、实际模型 ID 与相同 API Key。多个网卡会列出其他地址，选择与客户端连通的网卡。不要填写 `0.0.0.0`；那是监听地址。Windows 防火墙需允许本包 `runtime/python/python.exe` 在专用网络使用页面所示服务端口，程序不会自动修改防火墙或路由器。

开启鉴权后，本机客户端也需密钥；网页聊天在齿轮设置中填写 API Key。已有密钥不会回显，留空保存会保留；可生成新值替换，切回仅本机时可勾选清除。访问范围和密钥保存在本机配置，切换模型及升级后沿用。模型设置页始终绑定 `127.0.0.1`，局域网只开放模型服务。

## 自动更新与资源

设置页显示 **By T8star**、整合包及节点仓库，展开“关注与资源”可打开社媒、API、免费画廊和其他资源。聊天页 About 提供同样的入口，外部链接不会在启动时自动打开。

启动时后台检查 GitHub 最新正式版，离线不阻塞模型设置。点击 **一键更新** 会停止本启动器的服务、打开更新进度窗口；下载包通过 SHA256、文件清单与来源校验后自动安装，失败时保留或恢复旧版。完成后重新打开设置页，模型目录和配置保留。其他同目录的程序仍在运行时会拒绝替换，可关闭后重试。源码 Git checkout 使用 Git 更新。

## 命令行

`START-PORTABLE.bat settings` 只打开设置；`START-PORTABLE.bat start --no-browser` 保留原有无浏览器启动方式。命令行导入、模型准备、检查、更新和包完整性校验入口继续保留。

模型路径和本机设置不进入发行 ZIP；主模型/MTP 独立分发，Python、运行依赖及 VisionReady 的视觉权重仍由整合包提供。协议 1 与独立 ComfyUI 节点 1.3.0 保持兼容。
