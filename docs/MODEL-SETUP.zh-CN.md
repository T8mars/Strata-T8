# 整合包模型设置

双击 **START-HERE.bat** 打开本地网页。无需先安装主模型，无需安装 Python；分发时保留整个程序目录即可。其他批处理用于维护，日常使用只需这个入口。

## 已有独立模型包

1. 将分发者提供的完整模型包解压到 SSD，通常得到 **Strata-data** 文件夹。
2. 在网页选择该文件夹，或点击发现的本机模型。
3. 点击 **检查目录** 确认主模型和辅助文件齐全。
4. 点击 **保存并进入**。页面在后台配置并启动服务，然后进入聊天。

程序不会复制几十 GB 的模型到整合包；其他磁盘上的路径会保存在本机配置中。官方模型和准备完整的 SC117 模型均可选择。仅选择内部的 GGUF 文件夹会提示目录不完整。

## 尚无模型或只有官方 GGUF

展开 **下载 / 准备官方模型**，选择独立保存目录。完整下载最多约 89GB，另需模型预处理空间；确认流量和磁盘需求后才能开始。优先 ModelScope，其次国内镜像，再尝试 Hugging Face，固定版本和 SHA256 沿用现有下载器。

已下载的官方 IQ3_S GGUF 可放到所选目录的 `models/IQ3_S` 内；程序复用已校验的文件并补齐索引、Tokenizer 和 MTP。任务完成后选择准备好的目录，再保存设置。保留启动窗口，处理中可展开日志；中断后重试会复用已有校验通过的文件。

官方准备入口只处理官方 IQ3_S，不将 SC117 等其他变体混入相同目录。其他变体请选择其完整模型包。普通启动、发现、检查和导入不下载模型。

## 更换模型与服务地址

聊天页点击 **模型设置** 返回该网页，直接点击其他模型卡片，再点 **保存并切换模型**；程序会先停止本启动器的当前服务，然后应用新配置。输入无效或新端口被其他程序占用时，保留当前服务。SC117 变体显示为 **SC117 Uncensored · IQ3_S**，聊天页也显示这个名称。

NVIDIA 用户要选择聊天页的原生视频模式，在 **运行设置** 中选 **NVIDIA GPU 视觉**，勾选 **启用 NVIDIA 原生双帧视频分析** 并保存。保持关闭时使用抽帧分析，AMD 文本配置不提供原生视频。后续双击启动器自动进入已配置的聊天服务。

设置页只监听本机，默认从 17880 开始选择空闲端口；聊天/API 默认 8080，冲突时选择其他空闲端口，以页面显示的地址为准。OpenAI Base URL 为聊天地址加 `/v1`。关闭启动窗口或 Ctrl+C 会结束本启动器的服务，不操作其他程序的端口或进程。

模型按需加载，第一次文字、图片或视频请求可能需要等待。没有视觉权重的 NoModels 版本可先使用文本；VisionReady 包含兼容 Qwen 的视觉权重，Windows AMD 保持文本配置。

## 高级用法

`START-PORTABLE.bat settings` 只打开设置；`START-PORTABLE.bat start --no-browser` 保留原有无浏览器启动方式。命令行导入、模型准备、检查、更新和包完整性校验入口继续保留。

模型路径和本机设置不进入发行 ZIP；主模型/MTP 独立分发，Python、运行依赖及 VisionReady 的视觉权重仍由整合包提供。协议 1 与独立 ComfyUI 节点 1.1.1 保持兼容。
