## 实机复验

2026-10-16，Windows、i7-14700KF、128GB RAM、RTX 4060 Ti 16GB，使用既有外置 SC117 IQ3_S 模型。真实文本生成、图片形状/颜色问答与视觉进程恢复均通过。结束本次测试的视觉子进程后，主模型 PID 保持不变，后续图片请求恢复，复用 98 个缓存 token。

网页原生视频使用 12 秒、24 FPS、320×180 的合成 H.264/AAC 文件，按设置取得 288 帧、20 段，覆盖 0–12 秒，最后采样时间 11.96 秒、最大间隔 0.042 秒。CPU ASR 识别三段中文对白并按时间关联画面。测试片包含红色圆形向右移动和黑、蓝、绿背景变化。此结果验证数据通路和范围覆盖，不代表复杂视频理解准确率或逐词、口型对齐。

修复视觉恢复时重复执行完整模型显存准入检查的问题，并增加六项回归，覆盖正常驻留、冷启动、视觉重启失败、主模型同时退出及取消路径。默认加载路径保持原有检查。

## 分发与更新

两版包含完整 Python、CPU 语音运行环境与显卡运行库；VisionReady 另含视觉权重和配置。主模型、MTP、ASR 主模型、音频 projector 和 VAD 独立安装。完整 ZIP 保持标准 Deflate 格式，已发布更新器可直接读取。

发布检查包括严格应用/安装器/节点/分词器回归、网页视频逻辑、完整包文件及组件摘要、旧版升级、用户配置保留、EXE 启动移交和离线回退。实际检查结果与原生编译记录可在对应源码提交的 GitHub Actions 查看；未通过发布门槛时不公开 Release。
