# Strata-T8 0.1.45 同步兼容性

上游基线为 [v0.1.45](https://github.com/Niko1221/Strata/releases/tag/v0.1.45)，提交 `477ac13cbe8e582c20484871ce459d20d82df09d`。T8 版本为 `0.1.45-t8.1`，配套 ComfyUI 节点保持 1.3.0、14 个节点 ID 和协议 1。

## 保留的功能

EXE 启动、无模型设置页、外置模型目录、模型卡片自动切换、完整 API ID 复制、带密钥的局域网 API、网页与节点的视频分段、可选 CPU 语音转录、时标对白融合、进度恢复、自适应采样、跨段衔接、组件更新和离线回退继续保留。`roadmap.md`、模型、密钥和本机配置不进入源码仓库。

上游的新提示缓存与 T8 视频的临时视觉文件共用请求准备流程。视频预检不写入提示缓存；上下文超限拒绝请求时清除对应缓存项，准备失败仍删除临时视觉快照。新增三项回归覆盖这些交互，并保留已有原生视频、取消和视觉子进程恢复检查。

## 更新策略

同步模型元数据兼容、思考关闭参数、工具调用解析、提示缓存、配置诊断、Qwen3.6 及各后端的稳定修复。多用户、批量及实验性内核开关保持上游默认关闭，不向用户配置写入这些开关。

新安装器和整合包首次自动配置在低于 24GB 的 NVIDIA 卡上推荐 CPU 视觉编码器；已有视觉配置保持原样，用户显式选择 GPU 时继续使用 GPU。八项导入回归覆盖 24GB 边界、多卡选择、旧 CPU/GPU 配置保留和 Windows AMD 文本模式。网页未定制的采样参数按上游模型卡选择；显式发送的 API 采样参数继续生效。上游的性能数字只适用于其记录的硬件，不作为本机测量结果。

Qwen3.6 的安装与标准图片能力来自上游。T8 原生时序视频仍按能力协商开启，要求兼容的视觉编码器与串行推理；不能把新模型的标准图片支持视为其原生视频已经验收。主模型、MTP 和语音模型独立安装，升级不重新下载它们。

## 验证门槛与范围

同步验收覆盖应用、安装器、节点、分词器、网页视频和模型切换回归，检查自定义功能文件与本机私有配置的保留。Windows CUDA 从固定源码构建并包含原生视频协议；HIP/SYCL 共享源码另做编译检查。编译通过不能代替对应显卡实测。

运行记录见更新分支的 [GitHub Actions](https://github.com/T8mars/Strata-T8/actions)。实机推理需要空闲显卡与内存；未完成的硬件验收不得记为通过。发布包及公开版本以 [Release](https://github.com/T8mars/Strata-T8/releases/latest) 为准。
