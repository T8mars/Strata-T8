# 上游 v0.2.10 迁移验收

本地开发版本 **0.2.10-t8.1**，固定上游提交 `ffa80d73133ea5c548aefe57889a16e8085a938f`；源码、Control 和官方 Windows 引擎组件版本为 **0.1.56**。本记录随验收更新，实际公开版本以 GitHub Release 为准。

## 保留与同步

保留 T8 的 EXE 与首次无模型设置页、SC117/API 模型 ID 复制、自动停止并切换模型、带密钥的局域网 API、完整时长视频分段、原生时序输入、可选 ASR 与时间戳对白融合、视频进度恢复、自适应采样、品牌链接、组件更新及成功升级后的离线恢复。ComfyUI 独立仓库维持 1.3.3、协议 1；不要求节点跟随应用修改版本。

完整导入上游 v0.2.10，包括 Qwen DFlash2 选择与失败回落、低显存启动适配、已有模型文件复用、Windows 引擎更新恢复、DeepSeek Coder 和 DeepSeek 自带图片读取。启动不会下载 drafter 或主模型；DFlash2 使用已有的兼容文件，缺失时按上游规则回落。DeepSeek 图片读取仅向具备完整视觉塔的 pack 开放，默认关闭；已有文本 pack 的默认行为保留。

新 Tauri 桌面源码与测试已同步，T8 支持的整合包入口仍为 EXE 与网页；现有视频、ASR 和更新设置没有迁移到另一套入口。AMD、Intel 和 Metal 的上游改动不等于本机具备相应推理验收。

## 迁移中修复

- 混合图片与原生视频请求在视频编码后重复进入图片编码，覆盖了有序媒体数据；现在只执行一条准备路径。
- 工具参数兼容解析重新接入重复键、非有限数字、过深嵌套和无效 Unicode 拒绝规则；支持布尔属性 schema，并保留上游对声明字符串中引用工具标签的处理。
- 恢复不透明 MCP 图片引用的缓存边界与缺失图片说明，拒绝越界引用。
- 服务就绪记录去掉合并后重复写入，保留受异常清理保护的单次发布。
- 首次懒加载先检查 token bias 请求形状，加载引擎后再检查实际能力；Responses 错误保留参数名。
- ASR 后端 DLL 使用 Windows Unicode 路径加载，继续校验指令集和固定 ABI；修复中文目录下后端无法注册的问题，不改变系统区域设置或 Python 签名。
- 引擎安装在 Windows 短暂锁定文件时有限重试；失败仍恢复原目录，不忽略其他文件系统错误。分片不完整的 GGUF 优先报告缺失文件，不用缺失模板的信息掩盖它。
- Windows Python 查找优先使用便携环境；系统 Store 别名失败时继续查找 PATH 中可用的解释器。
- 桌面 Host 凭据文件改为设置精确的当前用户访问规则，清除 Windows 目录中原有的显式组权限；中文、引号路径与重复设置已复验。CI 的依赖安装、测试、类型检查和构建分别执行，测试失败不会再被后续构建成功掩盖。
- 新聊天记录功能保留视频计划、进度与音画证据，不存储视频文件、编码结果或请求二进制；恢复历史视频时提示重新附加文件。
- 上游同步预检按即将导入的路径检查忽略目录，避免枚举全部旧包、模型和构建缓存；覆盖与链接检查继续保留。

## 验证边界

本次没有下载主模型，也没有恢复独立的 IQ3 量化。DeepSeek 新视觉功能完成格式、配置和网页回归，未使用完整视觉权重实机推理。CUDA/HIP/SYCL 编译与目标显卡的实际运行分别记录；不以编译或模拟请求替代硬件验收。

本机 Windows 可建立 IPv6 监听，但系统策略拒绝 IPv6 本机连接（WinError 10013）；该连接测试单独跳过。IPv4 本机和带密钥局域网功能单独测试。私有 roadmap 不进入 Git 或分发清单。
