# 上游 v0.2.12 迁移验收

本地开发候选 **0.2.12-t8.1**，固定上游提交 `146df3c468739147f520ac3816de806f71232571`。源码、Control 和六种官方 Windows 引擎为 **0.1.58**；实际公开版本以 GitHub Release 为准。本记录在验收结束后补齐结果。

## 同步与保留

引入上游 0.2.11、0.2.12 的工具调用与并行结果匹配、低显存启动、请求计时、图像方向、引擎稳定性、DFlash2 和聊天存储改进。保留 52 个 T8 特性配置，包括 EXE、无模型设置页、模型切换、API 模型 ID、带密钥局域网服务、原生视频、完整时长分段、可选语音转录与时标对白融合、进度恢复和组件更新回退。

不下载主模型、MTP、ASR 模型或 drafter，不恢复独立的模型量化任务。桌面 Host 源码继续同步；便携发行版的入口仍为 T8 EXE 与网页。节点保持独立的 1.3.3 / 协议 1。

## 已复现并修正

- 自定义模型 API 的“应用”按钮位于长表单底部，普通窗口和窄屏均超出可见区域；直接填写模型 ID 后仍不可保存。改为顶部常驻“保存”，同时保存尚未点击“添加模型”的 ID。真实无头浏览器在 1280×720、390×800 下完成保存和刷新读回，页面无 JavaScript 错误；使用隔离临时配置与本地模拟接口，没有启动模型。
- 合并后首次懒加载没有保留回落参数；低显存再次启动丢失原取消信号和超时。真实测试子进程先复现，再验证回落、取消和 READY 截止时间。Windows 测试直接启动 Python 子进程，避免批处理父进程退出后留下测试子进程。
- 上游新聊天目录保护保留 SYSTEM/Administrators 的显式权限。已在中文、引号目录复现，改为精确用户 DACL，并验证新建嵌套文件继承正确权限、重复设置和原内容保持。

网页 API Key 增加明确保存按钮，保留即时生效和自动保存；存储不可写时仍提示只在当前页面使用，不声称持久化成功。分卡引擎回落继续传递配置中的启动超时，取消、超时或未确认退出直接返回。
