# 上游 v0.2.6 迁移验收

本地升级候选 `0.2.6-t8.1`，固定上游提交 `4b9e05a2a806a3fe24f7b2560d98626c37dade35`。本记录在验收结束前持续更新，不代表已公开发布。

## 范围

保留 T8 的 EXE/网页设置、SC117 与 API ID、自动切换、强制带密钥的局域网 API、视频采样/原生时序输入、全时长分段、ASR 对白融合、进度恢复、品牌链接及自动更新。新增 DeepSeek 本地文本 pack 接入。新 Tauri/Node 桌面入口独立评估，未替换 T8 入口。

应用版本 0.2.6；Control 和源码引擎版本 0.1.51；官方 Qwen 组件 0.1.50，DeepSeek 组件 0.1.51。六个 Windows 组件均绑定确切资产、摘要及官方签名清单。T8 CUDA 原生视频单独构建并核对源码输入和七种 SASS 架构；AMD 无原生视频能力声明。

## 限制

DeepSeek 当前仅文本；已有 native 产物不是完整 IQ2/IQ3 量化，未恢复独立量化任务。短提示与工具冒烟不代表大规模质量评测或稳定速度保证。

本次 DeepSeek 工具调用生成 41 tokens，用时 19.7347 秒，约 2.1 token/秒；这是解码时间，不含提示处理。RTX 4060 Ti 16GB / 128GB RAM，Full 6 专家、DSpark 关闭、上下文 2048。未做持续长文本或不同量化的性能对照。

多模态验收首次使用 48GiB 常驻专家预算时触发本次测试的低内存保护并停止自有服务；改为 24GiB 后完成上述图片、视频及 ComfyUI 验收。没有修改用户原配置，也不能据此保证不同内存占用下均可运行。

AMD/HIP、Intel/SYCL 和其他显卡的构建由发布 CI 门槛检查，本次 Windows 主机没有相应完整 SDK/硬件，不能宣称本机已编译或实机通过。视频仍使用采样帧，ASR 时间为段级近似；未据合成片链路验收宣称自然长视频理解精度提升。
