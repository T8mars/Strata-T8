# Strata-T8 0.1.42-t8.8 视频与对白验证

日期：2026-10-14。配套节点 1.2.0、协议 1。硬件为 RTX 4060 Ti 16GB、128GB RAM、Windows x64；主模型为 SC117 Qwen3.8-Flash-Next IQ3_S，语音模型为官方 Confucius4-R2T2 2B Q4_K_M + Q8 音频 projector。默认发行提供 CPU 语音组件，CUDA 语音组件未进入默认包。

## 功能与时长

- 网页及节点分别完成 20 个独立场景检查，覆盖修改参数、真实时长、稀疏窗口、对白范围、取消、字幕校正和默认关闭。
- 真实前端 Send 使用 12 秒合成 MP4、真实 HTTP、ASR 和 native 视觉模型：先按 6 秒上传，再改为 12 秒发送，分析范围为 0–12 秒，后半段对白与片尾绿色背景进入最终回答。12 项检查通过。DOM/FileReader 使用测试夹具，不计为浏览器文件选择器上传验收。
- 实际服务连续采样 54 个窗口通过：24 FPS 素材得到 288 个不同 PTS，末帧 11.958333 秒；1 FPS 素材得到 12 个真实帧和 24 个明确空窗口。高目标 FPS 不生成不存在的源帧，也不改变素材时长。
- 官方 ComfyUI VIDEO / torch CPU 验证实际 12 秒 MP4、截取 6–12 秒、非零原点和稀疏片段拼接。IMAGE 的源 FPS 必须由用户填写，不能把采样 FPS 当成素材 FPS。
- 真实 9 秒 AAC 视频 CPU/CUDA 转录得到三段完整中文对白，约为 0.150–1.955、2.840–5.115、5.990–7.855 秒。主模型引用对白 ID，正确描述红圆向右与背景变化；视觉输入按 1 FPS 采样。
- 独立语音节点与全程音画节点使用实际官方 VIDEO、HTTP 和模型响应验收。CPU ASR 保持主/视觉模型驻留。断开请求后 ASR 进程退出，下一任务恢复；中文及空格模型路径通过。
- 浏览器设置页确认独立模型路径、Q4 选项、CPU 默认值、默认折叠和默认关闭开关；扩展没有文件 URL 权限，文件选择器自动上传不计为通过。

## 解码与恢复

压力测试曾观察到 Windows 原生解码异常，底层库根因未确定。视频采样及音轨提取改为一次性工作进程，共用单媒体任务预算，避免原生解码异常直接终止主服务。只对非零退出自动干净重试一次；两次共用原超时，前次确认退出后清除半成品。取消、超时、非法输入和损坏结果不重试；双失败返回明确错误，不标成完整分析。

16 个隔离/重试用例通过，包含实际 worker 异常退出、超时、取消、排队取消、并发预算、半成品拒绝、重试及 HTTP 502 后下次请求恢复。本机隔离后的 worker 异常没有结束父服务或模型，同片段后续请求正常。最终没有残留媒体或 ASR worker；不声明原生库故障根治。

## 回归与分发

网页 38 项、视频/语音/媒体生命周期专项 163 项、节点 419 项通过。发行另执行完整应用、安装器、分词器、更新与资产门禁，最终记录以发行说明为准。

独立 CPU 组件约 145.47 MB，含 Python、原生库和依赖，不含语音 GGUF、projector 或 VAD。两版均提供 CPU 组件；VisionReady 另含既有视觉权重，Portable-NoModels 不含权重。更新保留 `asr-settings.json` 与 `.asr-cache/`。原始测试素材、用户配置、凭据和 roadmap 不进入 Git 或发行包。

这些结果验证列出的本机链路与边界，不代表其他 GPU、AMD/Linux 语音组件、真实长片、多人重叠或自然语音质量基准。时标仍是 VAD 段级近似，需校对；未实现逐词对齐、说话人分离或音乐/环境声识别。
