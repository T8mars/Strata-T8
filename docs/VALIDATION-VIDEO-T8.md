# 视频功能验收

目标版本：Strata-T8 0.1.42-t8.2 / ComfyUI 节点 1.1.0。以下分别记录数值、功能与生命周期证据；短视频结果不代表全部视频质量。

## CPU 与官方对照

- 完整应用回归 1445 项、安装器 463 项、实际 SC117 分词器 9 项，严格模式全部通过，无失败、错误或跳过。新增交付及构建校验另经 75 项专项回归通过；节点全套 259 项通过。
- 完整官方处理器 6 组真实像素输入，在项目模板和现有模型包模板下共 12 组完整 token/span 精确相同。覆盖双帧、四帧、奇数复制、混合图片/视频及显式采样索引。
- 固定官方处理器到真实 CPU ENCV、C++ 绑定的 5 组桥接检查，所有位置与后续文本偏移一致。C++ 有界读取合同有 37 个 CPU 检查。
- 真实固定视觉权重对官方视觉 forward：CPU 余弦相似度 0.99998987、归一化均方根误差 0.00451885；CUDA 分别为 0.99999285、0.00380594。默认图片编码对旧 helper 最大绝对差为 0；重复帧对与单图编码数值相同，交换帧序会改变输出。
- 实际 CFR/VFR、非零原点、中文路径、MP4 显示旋转及裁剪、损坏输入、字节/像素/帧数/时间限制、取消与超时恢复均经 CPU 回归。官方 VIDEO 的 trim/crop/rotation、拼接及旧版 File-only 接口经真实 Comfy API 探针核对。

官方源码固定于 Qwen `de4b8e4d43b917e7706784d8bb445c9af86a3540`、Transformers `55c3cc9f03cd4fbf2d27d382dcc8fcc544631f8e`，llama.cpp 使用项目固定提交。黄金对照使用独立测试依赖，不向接收者整合包引入 PyTorch 或 Transformers。

## 本机功能与资源管理

设备：Windows、RTX 4060 Ti 16GB、128GB RAM、32768 上下文。模型沿用已有官方 IQ3_S 和 SC117 IQ3_S，无本次权重下载。

8 秒、320×192 合成真值视频按 1 fps 取 8 帧：背景在 0–2 秒为红、2–5 秒为绿、5–8 秒为蓝，白圆持续从左移到右。官方及 SC117 的 frames/native 两种模式均识别颜色顺序、形状与方向；连续请求复用同一次 native 加载，API 卸载后确认主引擎和视觉进程退出。网页实际上传、附件后切换 native、发送与流式显示通过，控制台无错误；采样范围显示 0–7 秒。

SC117 的节点 V3 实际执行完成两段分析及一次汇总，三次请求使用相同主引擎/视觉进程；原文字、图片节点与 pending 请求取消清理均通过。

ComfyUI 0.38 真实 `/prompt` 队列完成两个 4 帧 native 分段、汇总、Extract、报告保存和 8 张 SaveImage。官方 ModelPatcher 登记的约 4 MiB 验收模型从 CUDA 移回 CPU；注册数 1→0，分配显存 4198400→0 字节，最终 Strata 双进程退出。这项验证同卡交接与下游队列，不代表本轮重跑完整扩散绘图。

## 分发边界

PyAV 15.0.0 / FFmpeg 7.1.1 的实际 Windows wheel SHA、259 个运行文件及 34 个 DLL 摘要固定在来源记录。构建前与打包副本均重新校验依赖和许可；仅重写库存不能掩盖篡改。真实 PowerShell 升级和本地 Git 上游同步探针覆盖视频模块、依赖、BUILD、用户配置保留、冲突回滚及私人路线图排除。

正式 CUDA 七架构构建、HIP 共用源码编译、发行 ZIP 全量审计及升级后的正式产物复验为额外发行门槛，结果以对应提交的 CI/Release 和本地最终回执为准。AMD 原生视频未启用，SYCL 独立源码未修改。长视频质量、ASR、连续快速动作及全平台硬件不在本次测量范围内。
