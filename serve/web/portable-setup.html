API 访问设置 · 本机 / 局域网

默认仅本机。开启局域网后自动重启本启动器的模型服务；正在生成的回答会中断。模型设置页始终只在本机开放。

开启鉴权后，DSH、ComfyUI 等客户端都需填写同一密钥；网页聊天在齿轮设置中填写 API Key。若其他设备无法连接，请在 Windows 防火墙的专用网络中允许本包 Python 使用当前服务端口。

可选语音转录 · 独立模型设置

视频分析时勾选“自动转录语音并分析对白”才加载语音模型。默认关闭，保存这里的路径不会启动转录或切换主模型。

目录需同时包含主 GGUF 与音频 mmproj。最小 Q4_K_M + Q8 音频 projector 共约 1.46GB，独立存放，不复制到程序目录。
